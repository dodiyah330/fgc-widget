2. Idle control WITHOUT heartbeat (scripts/ws-idle-probe.mjs, 3 min)
--------------------------------------------------------------------
- Session stayed open ~180s with no client traffic after the initial snapshot
- No spontaneous close in this window from this network path

Interpretation:
- From this developer network, a hard ~120s idle kill was NOT reproduced in 3 minutes.
- Client still lacked heartbeat/resync/sleep handling; production paths (proxy, Windows,
  sleep) can differ. Heartbeat every 25s is the correct permanent mitigation for idle
  proxy timeouts and is now shipped in the widget.
- Authoritative counter recovery on reconnect relies on the server's existing
  connect-time {"alerts","notify"} push (verified). A richer sync response that
  includes alerts is still recommended (see BACKEND_RECOMMENDATIONS.txt).
